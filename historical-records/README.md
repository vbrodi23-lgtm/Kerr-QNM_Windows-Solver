# Historical Records

This directory preserves non-production M02 research artifacts that were moved
out of active source, tool, and engineering-document locations on 2026-08-18.
Nothing beneath this directory is package data, a production import, a CI
target, or a current operator runbook.

The records intentionally retain their original contents, including historical
branch, pull-request, and policy statements. Those statements are evidence of
the work at the time; they are not current operating instructions.
